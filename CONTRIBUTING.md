# Contributing

Баг-репорты и небольшие улучшения приветствуются.

Перед Pull Request:

1. Проверьте скрипт на Windows 10 или Windows 11.
2. Не добавляйте автоматические registry tweaks, отключение защитных функций Windows или вмешательство в процесс игры.
3. Не добавляйте зависимости без необходимости.
4. Сохраняйте совместимость с Windows PowerShell 5.1.
5. Для изменений интерфейса приложите скриншот.

В сообщении о баге желательно указать:

- версию Stutter Guard;
- версию Windows;
- CPU / GPU / объём RAM;
- что было запущено в момент проблемы;
- текст ошибки или скриншот.
