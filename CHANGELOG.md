# Changelog

## 0.1.2

- Улучшено определение типа и модели диска игры.
- Добавлено отображение фактически применённого приоритета процесса.
- Одинаковые фоновые процессы объединяются в одну строку.
- Улучшено отображение длинного названия плана питания.
- Добавлена тёмная тема для поддерживаемых нативных элементов Windows.

## 0.1.1

- Исправлено обнаружение игрового процесса.
- Добавлен резервный поиск через Win32_Process.
- Исправлена нижняя строка интерфейса.

## 0.1.0

- Первый рабочий прототип.
- Системная диагностика.
- Проверка RAM, pagefile и Java environment variables.
- Игровой профиль с приоритетом процесса и временным планом высокой производительности.
- Автоматическое восстановление исходного плана питания.
