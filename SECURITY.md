# Security

STALZONE Stutter Guard работает через стандартные API Windows и PowerShell.

Программа не использует DLL injection, чтение памяти игры, собственные драйверы, отключение антивируса, обход TLS или скрытое изменение системных настроек.

Guard изменяет только выбранный приоритет игрового процесса и, если включена соответствующая опция, временно переключает активный план питания Windows. После выхода из игры исходный план питания восстанавливается.

Если найдено поведение, которое может привести к нежелательному изменению системы, не публикуйте чувствительные данные в issue.
